# @effect-l10n/messageformat

The Unicode MessageFormat 2 engine: the data model as an Effect `Schema`, the parser with source spans and tagged errors, semantic validation, type-level parameter inference and the reference formatter.

> **Status:** scaffolded ahead of milestone M1 ([#4](https://github.com/thomasfosterau/effect-l10n/issues/4)); nothing is exported or published yet. See [ADR 0006](../../docs/adr/0006-package-layout.md) for where this package sits in the workspace.
