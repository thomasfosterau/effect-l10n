# @effect-l10n/core

The authoring API: the locale model (BCP 47 tags, negotiation, fallback chains), `Message.make`, catalogs and stable message IDs, translations validated against the source locale, and the typed `defineConfig`.

> **Status:** scaffolded ahead of milestone M2 ([#5](https://github.com/thomasfosterau/effect-l10n/issues/5)); nothing is exported or published yet. See [ADR 0006](../../docs/adr/0006-package-layout.md) for where this package sits in the workspace.
